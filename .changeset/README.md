## What are changesets?

[Changesets](https://github.com/changesets/changesets) are a way to track and publish a coordinated set of package version updates. When you make a change that consumers should know about, run `pnpm changeset` and follow the prompts. Your answers will be turned into a `.md` file in this folder, which is committed alongside your PR.

When the PR merges to `main`, GitHub Actions opens (or updates) a "Version Packages" PR that bumps versions and writes changelogs. Merging that PR publishes the affected packages to npm under `@labmgm`.

## Quick commands

```bash
# Add a new changeset (run after making changes)
pnpm changeset

# Bump versions locally based on pending changesets
pnpm version-packages

# Publish (CI does this automatically; rarely needed locally)
pnpm release
```

See the [Changesets docs](https://github.com/changesets/changesets/tree/main/docs) for the full reference.
