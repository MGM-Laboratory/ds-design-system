# Installation

Pick what you need. Or install `@labmgm/react` and get the core library.

## Core

```bash
pnpm add @labmgm/react @labmgm/tokens @labmgm/tailwind-config @labmgm/fonts
```

## Optional packages

```bash
# Forms
pnpm add @labmgm/forms react-hook-form zod

# Data tables
pnpm add @labmgm/data-table

# Charts
pnpm add @labmgm/charts

# Rich text editor
pnpm add @labmgm/rich-text

# Calendar + date pickers
pnpm add @labmgm/calendar

# Command palette
pnpm add @labmgm/command

# Toasts
pnpm add @labmgm/toast

# Framer Motion presets
pnpm add @labmgm/motion

# Hooks
pnpm add @labmgm/hooks

# A11y primitives
pnpm add @labmgm/a11y
```

## Styling — pick one

### Option A: Tailwind 3 preset

```ts
// tailwind.config.ts
import preset from '@labmgm/tailwind-config';

export default {
  presets: [preset],
  content: ['./src/**/*.{ts,tsx}', './node_modules/@labmgm/*/dist/**/*.{js,mjs}'],
};
```

### Option B: Pre-compiled CSS (recommended for Tailwind 4 or no Tailwind)

```ts
import '@labmgm/tokens/tokens.css';
import '@labmgm/react/styles.css';
```

`@labmgm/react/styles.css` contains only MGM component utilities. It deliberately does not
include Tailwind Preflight or global `body` styles, so it can coexist with an app's Tailwind 4
reset and CSS.

## Requirements

- Node.js 20+
- React 18+
- For the Tailwind preset: Tailwind CSS 3.4+
- For Tailwind 4: use the pre-compiled CSS integration above
- For Next.js: Next.js 14+ (15 recommended)
- For `@labmgm/forms`: React Hook Form 7.55+ and Zod 3.25+ or 4+

## Tree-shaking

Every package ships dual ESM + CJS with `sideEffects: false` (except CSS files). Importing `import { Button } from '@labmgm/react'` only pulls Button, Slot, and CVA — nothing else.
