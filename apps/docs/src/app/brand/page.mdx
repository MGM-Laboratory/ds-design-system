# Brand

MGM Laboratory's visual identity is **playful, geometric, primary-colored, and human**.

> Our digital expression is *not* a recreation of the dense pattern. It is a **calm, premium product surface** that *quotes* the pattern as a signature — in a corner, in a divider, in a 404 page, in the favicon. The pattern is **the spice, not the meal**.

## The closed palette

Four brand colors. Off-whites. Grays. That's it. No purple, no teal, no pink, no orange. No gradients between brand colors. No tinted page backgrounds.

See **Color** for the full token list and accessibility rules.

## Two fonts

**Bricolage Grotesque** for display + hero. **Geist** for everything else. **Geist Mono** for code. No Inter, no Roboto, no system defaults.

See **Typography** for the scale.

## The pattern catalog

80 tiles — 10 Bauhaus shapes × 8 color schemes. Composed via `<PatternGrid>` with a deterministic, no-adjacent-repeat algorithm.

See **Patterns** for the catalog and compositions.

The geometric monogram lives at `<Logo />` from `@labmgm/brand`. Don't recolor it. Don't separate the shapes. Don't apply effects.
