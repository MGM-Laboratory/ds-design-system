# Changelog

Per-package changelogs are auto-generated by Changesets and live in each package directory (`packages/*/CHANGELOG.md`). This file tracks the monorepo as a whole.

> Versioning policy while on `0.x`: patch = fixes, minor = additive features (incl. breaking), major reserved for `1.0`.

## 0.1.2 — 2026-06-02

> **Stabilization release.** Every published `@labmgm/*` package is at `0.1.2`. Everything below was deployed within hours of each other while polishing the initial public cut.

### Highlights

- **`cn()` is now MGM-token aware.** `@labmgm/utils` registers custom font-size / radius / shadow / duration / easing tokens with `tailwind-merge` via `extendTailwindMerge()`. Before this, `cn('text-body text-white')` silently dropped `text-white` — every Button primary, Badge solid-\*, Banner inverse, etc. was rendering invisible text. This is the single most important fix in 0.1.2.
- **Inverse scope no longer fights component classes.** The `[data-surface="inverse"]` rule in `tokens.css` now only redefines CSS variables; it no longer forces `color` or `background-color` on the scope owner.
- **Self-contained surfaces declare their scope.** Card (all non-inverse variants), Dialog content, Drawer content, Popover content, HoverCard content, DropdownMenu content, ContextMenu content, Alert, Callout, CommandPalette content all set `data-surface="default"`. Tooltip sets `data-surface="inverse"`.
- **Light-tinted components use literal hex.** Toast, Alert, Callout use `text-[#0e1116]`, `text-[#3b4150]`, `text-[#6b7280]` literal — so they read correctly even if the Toast portal mounts under a body with `data-surface="inverse"`.
- **Calendar selected/today targets the inner `<button>`.** Previously the modifier classes hit the `<td>`, but the day button's own `text-ink` won the CSS cascade and produced invisible dark text on dark backgrounds. Modifier classes now use Tailwind's `[&>button]:` arbitrary selector.
- **Logo is now a faithful copy of `./logo.svg`** — the inner cutouts in the bottom-left square and the red circle are restored via `fillRule="evenodd"`.
- **Storybook coverage**: 166 stories across 40 categories cover every published primitive plus a Foundations / Inversion smoke test that renders the full matrix on default / muted / inverse surfaces.

### Breaking

- `bg-ink`, `border-ink`, `bg-ink-2` removed from internal usage in favor of `bg-surface-inverse`, `border-surface-inverse`, literal hex. If you used these classes in consumer code, swap to the same equivalents. `--ink-*` are text-only tokens per `DESIGN_SYSTEM.md`.

### Migration from 0.1.0 / 0.1.1

The 0.1.0 packages were published with broken `exports.import` paths (`.mjs` instead of `.js`) — they couldn't be imported. The 0.1.1 versions of `@labmgm/tokens`, `@labmgm/patterns`, `@labmgm/charts`, `@labmgm/forms`, `@labmgm/react` are unpublished tombstones. **Upgrade straight to `^0.1.2`** — older versions don't resolve.

## 0.1.0 — 2026-06-01 (initial release)

20 publishable packages, 4 shared configs, 3 internal apps (playground, storybook, docs). See the [`@labmgm/*` org on npm](https://www.npmjs.com/org/labmgm) for the full list.

- Foundations: `tokens`, `tailwind-config`, `fonts`, `utils`, `theme`, `hooks`, `a11y`, `motion`
- Brand: `brand`, `patterns` (80-tile catalog + composer), `icons`
- Components: `react` (~70 primitives), `layout`
- Forms: `forms` (Field, Wizard, StepRail + React Hook Form + Zod)
- Specialized: `data-table`, `charts`, `rich-text`, `calendar`, `command`, `toast`

Tooling: pnpm workspaces + Turborepo + Changesets. CI / release / canary / docs workflows on GitHub Actions.
