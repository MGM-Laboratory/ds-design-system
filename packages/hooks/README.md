# `@labmgm/hooks`

A small library of safe, predictable React hooks used across MGM Laboratory products.

```bash
pnpm add @labmgm/hooks
```

```ts
import {
  useMediaQuery, useDebounce, useThrottle,
  useLocalStorage, useSessionStorage,
  useClickOutside, useKeyboardShortcut, useCopyToClipboard,
  useIntersectionObserver, useResizeObserver, useReducedMotion,
  useControllableState, useIsMounted, usePrevious,
  useIsomorphicLayoutEffect,
} from '@labmgm/hooks';
```
